Cara Hosting Website HTML Gratis Permanen

Jika kamu ingin membuat web dengan URL khusus/kustom (seperti nama-web.netlify.app) tanpa karakter URL yang panjang, gunakan layanan hosting statis gratis berikut:

1. Netlify Drop (Paling Mudah)
  1. Unduh file HTML kamu menggunakan tombol Unduh File HTML.
  2. Buka situs app.netlify.com/drop di browser.
  3. Tarik (drag & drop) folder yang berisi file HTML kamu (pastikan nama filenya index.html).
  4. Layanan akan langsung membuatkan domain web publik gratis!
2. GitHub Pages
  1. Buat repositori baru di GitHub.
  2. Unggah file HTML kamu dengan nama index.html.
  3. Masuk ke menu Settings > Pages, lalu pilih branch main sebagai sumber.
  4. Website kamu akan aktif dalam 1-2 menit di tautan username.github.io/repository.
3. Vercel / Render

Kamu juga bisa menghubungkan akun GitHub ke Vercel/Render untuk deployment otomatis setiap kali ada perubahan file kode HTML.
